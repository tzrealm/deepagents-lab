# 周报生成流程

## 1. 收集素材
读取 `/notes/` 下本周所有文件，按项目分组。素材不足时，直接列出缺什么，不要编造。

## 2. 固定结构
- **本周完成**：3-5 条，每条 = 一句结论 + 一个数字
- **进行中**：标注阻塞点和所需支持
- **下周计划**：3 条以内
- **风险**：没有就写"无"

## 3. 硬性要求
- 不写"持续推进""赋能""闭环"这类空话
- 每条必须能回答"所以呢"
- 全文不超过 600 字
- 用简体中文，技术术语保留英文原词

## 输出
写入 `/reports/weekly-YYYY-MM-DD.md`
